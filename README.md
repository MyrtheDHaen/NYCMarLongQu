# NYCMarLongQu
This repository contains the code for a quantile-oriented analysis of the longitudinal 2022 NYC Marathon data, corresponding to D'Haen, M., Flórez, A., Molenberghs, G., Van Keilegom, I., Delecluse, C., and Verhasselt, A. (2025). Quantile regression for longitudinal within-race running data: the 2022 New York City Marathon. (Under revision.)
