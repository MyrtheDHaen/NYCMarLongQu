# NYCMarLongQu
This repository contains the code for a quantile-oriented analysis of the longitudinal 2022 NYC Marathon data.

The basis code and underlying functions can be found in NYCMarQu-main.R and NYCMarQu-functions.R, respectively, and corresponds to D'Haen, M., Flórez, A., Molenberghs, G., Van Keilegom, I., Delecluse, C., and Verhasselt, A. (2026). Quantile regression for longitudinal within-race running data: the 2022 New York City Marathon. _Journal of the Royal Statistical Society Series C: Applied Statistics_, 75(4):855–890.

More recent additions (a.o. confidence intervals and an additional analysis focusing on the Queensboro segment of the trajectory) are in the standalone file NYCMarQu-addon.R, which corresponds to D’Haen, M., Flórez, A., Van Keilegom, I., Molenberghs, G., Delecluse, C., and Verhasselt, A. (2026). Quantile methods for longitudinal running data: a New York City Marathon example. (Under review).
